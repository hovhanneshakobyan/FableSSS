---
description: Produce a concrete implementation plan for a feature or task before writing code
argument-hint: "<description of the feature or task>"
---

Follow the `task-planning` skill for: $ARGUMENTS

1. If the scope is ambiguous or has significant trade-offs, ask clarifying
   questions before planning.
2. Investigate the current codebase enough to ground the plan in reality
   (relevant files, existing patterns, constraints) rather than planning in
   the abstract.
3. Produce a plan using the structure: Goal / Steps / Open questions & risks
   / Out of scope.
4. Do not start implementing until the plan is confirmed, unless the task is
   small enough that the plan and the implementation are effectively the
   same size.
